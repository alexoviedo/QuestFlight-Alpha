# TextMeshPro shader resources

Source: the installed Unity uGUI 2.0.0 package, `Package Resources/TMP Essential Resources.unitypackage`.
Only its shader directory was extracted, preserving the package's paired asset GUID metadata. No example scenes, fonts or downloaded UI artwork were imported.
These are Unity-provided TextMeshPro support shaders and includes, distributed under the package's Unity Companion License; see LICENSE.md copied from the installed package. The shipping interface uses the mobile distance-field variant through its authored font materials. Package source was not modified.
