# Interface assets

Inter Regular and Semibold are static instances (optical size 14, weights 400/600) of the Inter variable font from https://github.com/google/fonts/tree/main/ofl/inter, downloaded 2026-09-21. Source: https://raw.githubusercontent.com/google/fonts/main/ofl/inter/Inter%5Bopsz,wght%5D.ttf . Licensed under the SIL Open Font License 1.1, reproduced in OFL.txt. Static instances generated with fontTools 4.63.0; retain font copyright/name records. The font license permits embedding and redistribution subject to its terms.

Generated Inter SDF assets embed these font glyphs; same license applies. Interface theme, rounded panel shader, meshes and typographic control hints are original QuestFlight project content, generated by ProductInterfacePolishAuthoring. Existing startup photography retains its existing source record. No new external photographic assets.
