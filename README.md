# QuestFlight Alpha

QuestFlight is an experimental standalone Meta Quest 3 flight simulator, shared for personal use and tester feedback. The product source repository remains private.

## Installation and scope

Sideload the APK onto a Quest 3. This release retains the GitHub sideload signing identity; Meta-channel builds have a different signature and cannot be updated in place with it.

The included changes received focused checks and headset reviews. This exact APK passed build, scenery-payload and signature checks, and was installed and launched on Quest with its hash verified. See the release notes for remaining limitations; no sustained-framerate or thermal acceptance is claimed.

This is a free GitHub development prerelease, not a Meta Horizon Store release or a certified training device. Third-party license terms and notices remain applicable.
