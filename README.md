# QuestFlight Alpha

QuestFlight is an experimental standalone Meta Quest 3 flight-simulation alpha.
The source repository remains private; this public repository provides
headset-tested APK downloads and checksums.

## Current release

**QuestFlight Map Boundary Recovery V1**

- [Download the APK](https://github.com/alexoviedo/QuestFlight-Alpha/releases/download/questflight-map-boundary-recovery-v1/QuestFlight-production.apk)
- [Download the SHA-256 checksum](https://github.com/alexoviedo/QuestFlight-Alpha/releases/download/questflight-map-boundary-recovery-v1/QuestFlight-production-SHA256.txt)
- [Read the release notes](https://github.com/alexoviedo/QuestFlight-Alpha/releases/tag/questflight-map-boundary-recovery-v1)

APK SHA-256:
`3d6bd54604291ca5701d746393b92558ae11ae13c3a6574c57d418b5d763af8d`

Application ID: `com.alexoviedo.t2.questflight`

This build adds a faded, native-JSBSim-authoritative recovery when Free Flight
approaches the finite authored map boundary. It also includes the previously
accepted startup showroom, Demo takeoff restoration, external controller path,
and bare-hand yoke exclusion.

## Scope

This is a development prerelease distributed through GitHub for sideloading. It
is not a Meta Horizon Store release and does not claim certified fidelity,
training credit, broad device compatibility, or generalized Quest performance.
