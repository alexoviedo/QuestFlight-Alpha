# QuestFlight 0.1.0 Alpha 16

This standalone Quest 3 prerelease adds the Boulder SGS 2-33 soaring flight and repairs the runway-start flow. It is a development build for sideloading and tester feedback.

## Changes

- Adds the SGS soaring operation with ground aerotow preparation, launch/tow/release, airborne soaring practice and the sailplane training/demo flows.
- Makes **Skip preflight and start launch** enter the cockpit directly. It no longer routes through a duplicate menu or requires a separate Resume selection. If physical launch gates are not clear yet, the tow pair remains staged and clearance retries automatically when they are.
- Keeps rope, traffic, brake, control-centering and runway-clearance conditions active when the pilot skips the checklist; skipping provides no checklist credit.
- Consolidates the accepted Boulder scenery, cockpit, ambient traffic, C172 training and menu work from the intervening development commits.

## Validation and limits

- Direct runway-start regression: 1/1 passed. Android manifest and signature checks passed, and all 1,912 authored scenery payload files matched the inventory.
- Unity generated the ARM64 player and Gradle project. The integrated build wrapper ran out of host disk space during Gradle asset hashing; `assembleRelease` then completed successfully from that exact generated project. No scenery, render-quality or simulation-time reductions were made.
- The broader PlayMode batch is not fully green: 51 passed and 4 failed in previously identified unrelated expectations/fixtures. The focused direct-start regression passed.
- This exact packaged revision has not had a worn-headset acceptance test. Do not treat the Quest installation of the preceding candidate as acceptance of this APK. Sustained Quest frame rate, thermal behavior, certified aircraft fidelity, FAA approval and training credit are not claimed.
- Native JSBSim remains the required product flight authority. This is a development prerelease, not a Meta Horizon Store release or a certified training device.
