# Visible foliage improvement — September 9, 2026

The user asked for a substantial visible improvement before another headset test, then reported: “the tree grouping representation is looking much better from the images!” Keep this composition as the visual reference; that feedback is image acceptance, not hardware performance or worn stereo acceptance.

## Delivered visual changes

The connected pilot previously distributed 304 persistent branch clusters largely along one upper surface, plus 126 interior clusters that disappeared with distance. The new composition uses 632 persistent upper/middle clusters and 172 lower near clusters. It follows the same independently inspected 2,025 m² footprint and measured upper heights. Lower foliage placement remains estimated. It preserves the original wood and six-tree ownership, source openings and leaf scale; no photographic sheets, opaque shell or scaled giant tree cards are added.

The grove selects existing broadleaf atlas patches instead of mixing in the wispiest needle-like patches. Its main canopy now includes a persistent middle layer, making the grouping fuller at ordinary oblique distances rather than concentrating the improvement directly below the aircraft.

The previous shader divided each leaf pixel's RGB by that same pixel's luminance, flattening the existing texture's light/dark detail. The revised branch response retains restrained contrast relative to the measured opaque-pixel median linear luminance of the existing atlas (0.1271). The grove additionally shades estimated interior foliage using offline height fractions. MSAA edge coverage is reconstructed around the unchanged alpha-test threshold rather than sending raw filtered alpha directly to alpha-to-coverage. Atlas RGB and alpha source files are unchanged.

The shared primary branch-card material enables the texture/coverage response for existing trees throughout the map. It does not add tree geometry, instances or textures. Hero/impostor atlases keep their original response; the existing separate neighborhood artwork is not replaced. This broader shading change and the one-grove geometry change have different scopes.
