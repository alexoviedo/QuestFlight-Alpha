# Current authoring and artifact validation

The shipping target remains standalone Quest 3 Android ARM64/Vulkan/OpenXR. Native JSBSim is the sole flight authority; authoring tools do not reconstruct product hierarchy at runtime.

Full aerial source textures are ignored inputs. The copied full page manifest in StreamingAssets is SHA-bound to the reviewed compact source manifest. `FullMapAerialClipmapAssetAuthoring.VerifyExistingAndroidBundlesBatch` can validate existing artifacts without regenerating 1,873 source JPGs. Its evidence operation is `verify_existing_loaded_artifacts`: every one of 469 binary bundles is opened and every expected texture address, dimensions, ASTC 10x10 format and mip chain is checked. The preliminary Python sidecar inventory alone never passes the final gate. `EnsureVerifiedBuildArtifacts` opens actual assets again and requires current byte/manifest/verifier identity before APK packaging. Historical source generation remains a separate reconstruction prerequisite.

Building bundles use exactly 144 regions with 576 authored mesh addresses. Current source database, terrain, tower exclusion authority, actual compiler/helper bytes, each mesh input SHA, Unity 6000.3.8f1 and Android build options enter the cache identity. The index records each binary SHA/length/CRC/content hash and its real root manifest identity. Preflight loads every bundle and expected Mesh. A lone sidecar, missing index/region, changed binary or stale input fails before BuildPlayer. `FullMapBuildingClipmapAssetAuthoring.RepackExistingAndroidBundlesBatch` repacks existing current meshes without regenerating geometry. Ignored staging/backups live in Library, outside StreamingAssets; caller/product validation completes before activation and the success stamp is written last.

Watercraft revalidation requires the original placement SHA to remain identical and the existing six output hashes/compiler identity to be certified. A change to anchors, clearances, placement mode or geometry requires source-backed recompilation. The temporary derivative FBXs under `Assets/__ReservoirWatercraftTemp` were absent; the five recorded raw archives are locally available and match their reviewed hashes. Six current derivatives were generated externally with the existing producer and installed Blender 5.1.2, recording each archive, member, compiler, tool and new FBX identity. Explicit current provenance retains the historical records and existing rights restrictions; it does not claim historical byte-identical FBX restoration. The pinned importer contract uses raw source Mesh vertices already authored in product XYZ axes, scale 1, no materials/animation and `bakeAxisConversion=false`. A controlled Unity comparison proved that setting this flag true reverses every raw vertex longitudinally despite unchanged dimensions; three independently frozen original geometry landmarks reject that output. Placement headings must never compensate for an importer-basis change. Run `ReservoirWatercraftAuthoring.ValidateCurrentDerivativeImportsBatch`, then `BuildBatch`, alignment/orientation validation and stereo QA. The compiler updates existing feature/group/LOD objects and Mesh assets in place and writes saved-output identity only after prefab save succeeds. Remove only the newly owned private import staging after successful compilation. Surgical topology repairs can carry their own byte-preserving evidence; they do not establish that BuildSerializedFeature executed.

Reconstruction uses the shared current schema 2 airport-aircraft producer for all 35 placements (17 powered aircraft and 18 sailplanes). The three older calibration stands remain historical diagnostics. Final composition metadata records its actual output hashes while retaining historical input hashes separately; the missing pinned external 6 km normalized OSM input blocks clean full reconstruction.

Reflection rendering uses an isolated preview scene and a dedicated Editor bake camera. Visibility queries only its owned opaque MeshColliders, independent of unrelated open scenes or layer 29 geometry. Shared-folder mesh cleanup never deletes unowned vegetation, animation controllers and owned states update in place, replacement ambient directors rebind wildlife references, and Traffic V2 authoring preflights/preserves current road/lane/contact bindings before asset mutation.

Focused Editor and Windows-host material-free bundle fixtures establish local code behavior. They do not establish Android APK content, stereo comfort, physical Quest frame/thermal performance, third-party rights, or store acceptance. R11 remains separately assessed until real complete artifact and applicable clean-source reconstruction checks are recorded.
