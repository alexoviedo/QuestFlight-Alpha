# Training clarity and app navigation implementation

Approved scope: [revised training clarity plan](FLIGHT_TRAINING_CLARITY_PLAN_2026-09-19.md), including the September 19 request for consistent navigation throughout the application.

## Implemented

- One serialized navigation owner for startup, Free Flight, Demo, training and seat calibration. Left Menu opens app pause/navigation; B or Y goes back/cancels; A or controller ray + trigger selects a labeled action. X optionally repeats/shows the current lesson cue. The Meta button remains system-owned.
- Main menu is reachable from every mode. Active-session exit requires confirmation; cancellation preserves the paused context. Return clears demonstration/training control ownership and restores the initial aircraft state through native JSBSim. Completed lesson progress and saved seat settings remain intact.
- Named calibration, restart, demonstration, explanation, captions and eligible control-assistance actions replace changing face-button commands. Focus loss pauses active flight. Input consumption and neutral/release gating prevent held menu selections from grabbing controls or applying Touch brakes on return to flight.
- Short original scripts across the six existing lessons, a first-flight sequence that introduces references incrementally, indicated-value grading for gauge-following tasks, phase-specific automatic correction/recovery cues, earlier rollout prompts and prioritized go-around instructions. Optional reduced-prompt attempts retain safety guidance and are distinguished from guided/assisted completion.
- Editor-authored cockpit markers and a temporary airport-reference outline. Instrument markers belong to the airframe rather than seat calibration; the attitude reference projects the internal ball pivot onto the instrument face. No avatar, extra runtime camera, light, physics authority or online voice service was added. There are 83 offline narration clips with existing GUIDs preserved.
- Left Touch stick provides the trim action referenced by the lessons. The user's pre-existing Touch trigger-brake changes were preserved. Menu/flight handoff gates both sticks, face buttons and triggers.
